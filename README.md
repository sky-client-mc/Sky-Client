# ☁️ Sky Client

**Sky Client** is a Minecraft PvP client focused on performance, customization, and a clean user experience.

> ⚠️ Sky Client is an independent third-party project and is not affiliated with, endorsed by, or sponsored by Mojang Studios or Microsoft.

## ✨ Features

* 🚀 Performance optimizations
* 🎯 PvP-focused features
* 🎨 Customizable interface
* 📊 In-game HUD
* ⚙️ Configurable settings
* 🔑 License-key system
* 🔄 Regular updates
